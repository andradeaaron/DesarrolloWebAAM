Bienvenido al panel de la cafetería

Esta página nunca se recarga: cada opción del menú superior pide datos al servidor en segundo plano con la Fetch API y solo actualiza esta zona.

Menú
Lista los productos desde productos.php (JSON) con búsqueda en vivo y filtro por categoría.
Detalle y eliminación
Cada tarjeta abre una ventana modal con los datos de producto.php?id=....
Nuevo producto
El formulario se envía con FormData por POST, incluida la fotografía.

Abra las herramientas del navegador (F12 → Network → Fetch/XHR) para ver cada petición.
